# Code of Conduct

Galleon follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about code, not people. Harassment of any kind isn't tolerated.

Report problems privately to the maintainer via [GitHub Security Advisories](https://github.com/ironblaster/galleon/security/advisories/new) or by opening a confidential discussion with @ironblaster.
