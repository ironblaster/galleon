# Security policy

Please report vulnerabilities **privately** through [GitHub Security Advisories](https://github.com/ironblaster/galleon/security/advisories/new), not through public issues.

In scope: anything in this repository that could leak secrets (for example `.env` handling, the indexer exporter, or logs), or that weakens the default exposure of a service.

Out of scope: vulnerabilities in the upstream applications themselves. Please report those to the upstream projects.
